Layout primitives

The composition primitives are stateless layout classes. Each one solves one geometric problem and composes with the others. Most layouts are built by stacking these without writing custom CSS.

All primitives use var(--gap) for spacing between siblings. Override per-instance with style="--gap: 0.4rem" for tighter groups or style="--gap: 1.5rem" for airier ones.

.column

Vertical stack with gap between siblings.

A
B
C
<div class="column">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>

.row

Horizontal stack with gap. Wraps to a new line when content exceeds the container width. Items align vertically centered by default.

A
B
C
<div class="row">
  <div>A</div>
  <div>B</div>
  <div>C</div>
</div>

.split

Two equal columns. Each child takes 1fr regardless of content size.

left
right
<div class="split">
  <div>left</div>
  <div>right</div>
</div>

.spread

Horizontal layout with first child pushed to the start, last to the end, and middle children distributed evenly. Common for top bars and toolbars.

brand
center
menu
<div class="spread">
  <div>brand</div>
  <div>center</div>
  <div>menu</div>
</div>

.lcr

Three-region horizontal layout: leading, center, trailing. The center child is centered in the container regardless of the leading and trailing widths.

left
centered
right
<div class="lcr">
  <div>left</div>
  <div>centered</div>
  <div>right</div>
</div>

.tmb

Three-region vertical layout: top, middle, bottom. Mirrors .lcr on the vertical axis. Useful for cards and panels with pinned edges and centered content.

top
centered
bottom
<div class="tmb" style="block-size: 12rem">
  <div>top</div>
  <div>centered</div>
  <div>bottom</div>
</div>

.flank · .flank-end

A leading and trailing pair where one is fixed and the other grows. .flank grows the trailing child (use for icon + label rows). .flank-end grows the leading child (use for label + control rows).

icon
leading is fixed, trailing grows
leading grows, trailing is fixed
btn
<div class="flank">
  <div>icon</div>
  <div>label</div>
</div>

<div class="flank-end">
  <div>label</div>
  <div>btn</div>
</div>

.grid

Auto-fit responsive grid. Children fit as many columns as will accommodate --grid-min (default 16rem). Each cell is at least --grid-min wide and at most one full row.

1
2
3
4
5
6
<div class="grid" style="--grid-min: 8rem">
  <div>1</div>
  <div>2</div>
  <div>3</div>
  <!-- … -->
</div>

.frame

Fixed aspect ratio container (16:9 by default). The first child fills the frame with object-fit: cover. Use for image and video placeholders that maintain their aspect ratio while the content adapts.

16:9 frame
<div class="frame">
  <img src="…" alt="…">
</div>

.stack

Single-cell grid where every child occupies the same cell. Use for layered content — a hero image with text overlaid, a chart with annotations on top, a card with a corner badge.

background layer
badge
<div class="stack">
  <div>background</div>
  <div style="justify-self: end;
              align-self: start">
    badge
  </div>
</div>

.hud

Single-cell overlay with nine directional anchor slots: ↖ ↑ ↗ ← • → ↙ ↓ ↘. Children are sized to their content and pinned to the slot they're tagged with. The container is hit-test transparent; children opt back in to receive clicks. Used for KPI cards (label + value + tag), chart legends, badges, reticles.

label +12% $284k footnote 2026 Q4 
<div class="hud">
  <span class="↖">label</span>
  <span class="↗">+12%</span>
  <span class="•">$284k</span>
  <span class="↙">footnote</span>
  <span class="↘">Q4</span>
</div>

.hud-grid

Same nine anchor slots as .hud, but as actual grid cells with content sizes. The center row stretches; corners and edges take their content size. Use when the slots need to occupy space rather than overlay it.

↖
↑
↗
←
•
→
↙
↓
↘
<div class="hud-grid">
  <div class="↖">↖</div>
  <div class="↑">↑</div>
  <div class="↗">↗</div>
  <!-- … nine total cells -->
</div>

.hero

Five-slot panel with chrome around scrollable content. .top and .bottom span the full width; .left and .right flank the middle; .main scrolls. Used inside drawers, modals, and split-pane regions.

top
left
main (scrolls)
right
bottom
<div class="hero">
  <div class="top">…</div>
  <div class="left">…</div>
  <div class="main">…</div>
  <div class="right">…</div>
  <div class="bottom">…</div>
</div>

All slots are optional except .main. Omit any others and their tracks collapse to zero. .hero fills its container, not the viewport — for application-root layouts use .page instead.

Setting gap

All composition primitives use var(--gap) for spacing between siblings. The system value is fluid: it stays tight across phone-to-desktop widths and only ramps up at projector and TV scale.

:root {
  --gap: clamp(
    0.25rem,
    calc(0.25rem + 1.75rem * pow(100vi / 3000px, 3)),
    2rem
  );
}
Current resolved value at this viewport width

Per-instance overrides opt out of the fluid behavior: style="--gap: 0.4rem" for a tight chip row, style="--gap: 1.5rem" for an airy section. The fluid behavior resumes everywhere else.
