Mental model

Three formulas drive the system: one for color, one for type, one for space. Set tokens with intent on any element, the system computes the rendered result. Adjust the controls below to see each formula respond.

Color

Two independent axes. --bg ranges from 0 (transparent) to 1 (loud chromatic) and controls surface presence. --fg ranges from -1 (full neutral contrast) through 0 (invisible) to 1 (vivid chromatic) and controls ink. --hue rotates the entire formula.

Surface Sample text Body copy uses the same formula.

The OKLCH formula behind these tokens is hidden inside the system. Authors write intent (a number between 0 and 1) and the system computes the rendered color. Theme switches, dark mode, and contrast flipping happen through the same formula.

Type

One ratio drives the scale. --type takes integer steps (0 is body, positive is bigger, negative is smaller). Letter-spacing and line-height adjust automatically — bigger text gets tighter spacing.

The quick brown fox jumps over the lazy dog.

The full scale

type 3 — display heading

type 2 — page title

type 1 — section title

type 0 — body text (default)

type −0.5 — slightly smaller

type −1 — secondary text

type −1.5 — captions

type −2 — micro labels

Type doesn't cascade. Set --type on each element that needs sizing; children don't inherit the parent's value. The non-cascading behavior is intentional — it keeps text rhythm local and predictable.

Space

--gap is fluid. The system value uses a clamp with a cubic curve over viewport width — the gap stays tight (around 4–8 pixels) across the full phone-to-desktop range and only ramps up at projector and TV scale. 

--gap: clamp(
    0.25rem,
    calc(0.25rem + 1.75rem * pow(100vi / 3000px, 3)),
    2rem
);

Resize the window to see the gap respond. Per-instance overrides (style="--gap: 0.4rem") opt out of the fluid behavior.

Layout primitives (.row, .column, .grid, etc.) read --gap for spacing between siblings. The page layout reads it for slot padding. One token, two jobs, one curve.

These three formulas plus a layout system are the whole library. Everything else is the parts list.
