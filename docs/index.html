stick.css

A CSS design system organized around three formulas — color, type, space — and a small set of layout primitives. Set tokens on any element, compose layouts from declarative classes, ship.

The three formulas

Color comes from one OKLCH formula. Set --bg for surface presence, --fg for ink contrast, and --hue for identity. Themes, dark mode, and contrast flip automatically.

Type comes from one ratio. Set --type per element. Integer steps, body is 0, line-height and letter-spacing adjust automatically.

Space comes from one fluid token. --gap stays tight across phone-to-desktop widths and ramps at projector scale. Layout primitives use it; the page layout uses it for slot padding.

Install

Add the link tag to your HTML:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/Deufel/toolbox@ddd1642/css/style.css">

That's the whole installation. No build step, no configuration file, no JavaScript required for styling.
